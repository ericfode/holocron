# Deck lists, discards and game history as model inputs (hist_train.py, run h1, 2026-10-15)

Data: 811,018 decisions from 6,176 recorded games (4 x 702 c-clock mirror games with `--record`, pivots-rec-1 and the
on-policy recordings), each with the opponent's real hand (`from_replays.js --labels`). Held out by game seed: 618
games; scores on 20,000 held-out rows. 8,000 steps, batch 256, dm 64, 2 layers, 4 heads. Targets for h1/h4 are
tx-t10's own latents (frozen). Run on the desktop GPU.

hand_logloss is nats per row over 2,048 card buckets; hand_recall is the share of the opponent's real hand among the
model's top guesses of the same size.

Reading:
- Every learned model beats the leader prior and card counting on the opponent's hand (8.47 vs 9.09 nats) and on
  the opponent's next move (top-1 0.40 vs 0.13). Card counting has the better log-loss of the two baselines but the
  worse recall.
- Discards, the unseen-card tokens and the move history add nothing measurable at this length (within 0.03 nats,
  0.006 recall, 0.005 win accuracy). pool learned fastest (hand 8.33 at 1,000 steps, base 8.69), then base caught up:
  the lists speed learning, but base learns the same from the leaders and the board.
- Trained from scratch, these models stay well below tx-t10 on explained_h1 (0.735 vs 0.863), come close on h4 (0.70
  vs 0.72), and estimate the winner better (log-loss 0.446 vs 0.463).
- hist costs about 9x more per step than base (2,597 s vs 272 s for the run).
