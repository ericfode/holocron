## What the current representation guarantees

`structural_tokens` and `encode_program_bank` retain sorted object keys, ordered list indices, typed numeric leaves and their full key/index paths; numbers use the saved training scale and signed log1p. `make_contrast_model.encode_program_bank` multiplies edge embeddings by depth gates, combines each path with its typed value through a nonlinear leaf network, then takes an active-token mean. This permits literal-position distinctions. It does not guarantee an injective representation or a learned execution algorithm; a nonzero numeric gradient establishes neither. No obvious literal deletion or output-column permutation appears in this source read.

Before interpreting fresh outcomes, the audit must decode the frozen tensors back to reviewed paths/literals, check shape/mask/finite values and distinguish input collisions from learned near-collisions.
