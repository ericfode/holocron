# Identifiable native effects: prepared, not executed

This collector reuses the public play-from-hand fixture machinery from PR35 in
new files. It selects twelve complete, already runtime-admitted card definitions
from the actual 27-list corpus, without changing Kessel, the compiler or coverage.
The full generated rows, token dependencies and source hashes are in the frozen
`collection-plan.json`; the native loader checks every selected compiler field.

Seven TRAIN identities and five held identities form three held template families.
Four public worlds produce 48 roots and the fixed 21/15/7/5 split. Each root has
one predeclared intended query, including a distinct observation mode:

- Chosen target: an actual offered target commit is necessary for future labels.
- Upgrade attachment: actual payment, attachment parent and settled endpoint are necessary.
- SEC051 area anchor: a named public unit is observed after a paid settled play;
  it does not imply a target-selection action or target-membership label.
- ASH048 self entry: native source entry and Shield creation are observed.

The native receipt contains snapshots and actions, not computed training labels.
The separate `native_effect_v2_data.py` converter checks the raw witness and
retains unknown masks for unavailable, declined, dead, error or pending outcomes.
Unchosen candidates are never zero-filled. Rich and sparse supervision retain
identical source/removal/membership masks; sparse TRAIN masks hide only the five
target-delta columns. Neither preparation nor an existing admitted row is proof
that a new fixture or an entire card is behaviorally qualified.

All draw piles and the opponent hand are empty. Source cards are in our own
known hand; fixture units, attachments, Shields and resources are public. Gungi
is a lawful non-Vehicle Jedi host for Knight's Saber; native target queries and
exact snapshot/load roundtrips check the constructed attachments. Ordinary
upgrades enter `registration_order` once, while physical Shield tokens use both
native token and upgrade links. SEC051 enemy units and the JTL079 chosen host
are planned to survive; conversion must verify actual surviving native endpoints
and unchanged Experience, leaving SEC051's full death hook unqualified.

The native collector permits at most five `Engine::apply` attempts per root,
240 in total. The shared campaign has a 256-call ceiling. Every attempted apply
first durably writes its intent, including calls returning errors. Pending prompts
are preserved without inventing a continuation. There is no fallback target or
automatic retry. No tests here compile or execute the native collector.

`supervise.py` holds the authoritative shared hash-chained campaign lease before
preflight through cleanup. It reserves 240 calls, zero optimizer updates and zero
neural forwards. Its native phase has 90 cumulative active seconds including all
builds and failures, one Cargo/jobserver build worker, offline locked dependencies,
and a 1 GiB sampled owned-process RSS stop. It samples concurrent live RSS sums;
historical per-PID peaks are metadata only. Final rusage supplements sampling
with parent peak plus maximum single-child peak. This is not an OS memory
reservation or CPU-affinity claim. The prior task7 Cargo target cache may be reused;
mutable cache hashes are provenance, not required execution inputs.

Only root may freeze the shared config and authorize the same command with
`--execute`. A pending or damaged campaign journal blocks every later phase.
Keep every failed attempt and cumulative debit. No training, opponent execution,
paid jobs, deployment or old evidence edits are part of this collector.
