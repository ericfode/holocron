# Review: public inputs, action binding and learned transfer

The new experiment can test whether two input additions improve learned transfer. It cannot retroactively identify them as the cause of every previous failure. PR36's observed typed-input conflicts were zero; its held space-count rule already had Space/Fighter globals, and its chosen-only attachment labels did not observe the unchosen host. The later LAW_045 and LOF_215 native counterexamples establish limitations outside those old observed masks. Their exact bound interpreter was a deterministic diagnostic, not a learned architecture ablation.

The prior negative results remain the reference: rich typed family-held error 1.641130 versus literal zero 1.414729, then the fixed TRAIN sanity fit reached 1.599818 held error while zero beat it on every held effect head. Correct and arbitrary fixed-shuffled TRAIN packets both fitted closely. This supports working optimization/target plumbing and leaves input sufficiency, coverage and transfer open; it supplies no capacity diagnosis.

## Frozen intervention and what it isolates

Root selected the smallest input factorial. **C** adds six printed-aspect counts for each source-relative owner and knownness, plus six candidate printed-aspect bits and knownness. It adds no new trait channels. **R** adds the pre-action `candidate_is_intended_host_or_target` relation and knownness. C does not supply a source-program-specific query answer; it does deliberately engineer the public owner/attribute association. R is proposed action intent, never final parent or offered membership. Existing ownership, `same_source`, own Space/Fighter counts, legacy trait bits and base/leader aspects remain in every cell. Passive aura has no external intended target and receives neutral R `[0,0]` for every candidate.

All cells use identical padded tensor shapes, original 18/34 prefixes, the same expanded input projections into width 16, common parameter names/counts, cloned initialization per seed, TRAIN rows/order, masks, target values, schedules and optimization. Omitted feature channels use one frozen neutralization rule; this is an input ablation, not a claim that an omitted predicate is physically false. Keep the pre-ablation public arrays and observation masks immutable. Freeze TRAIN-only transforms once on the common input contract; do not refit scales separately by cell. Disclose projection/table parameter growth relative to the old model, while proving equality across these four cells.

No panel encoder, nonlinear unit pooling, extra helper statistics, new model width, production own-deck change or engine coverage expansion belongs to this intervention. In particular, this does not isolate an explicit typed resolver architecture versus pooling at equal information. That is a different experiment.

## Readouts, controls and falsification

Use three predeclared seeds (17/29/43) and the same budget in all four main cells; prefer this to additional learned arms at one seed. Freeze evaluation batches, step count and all attempts before launch. Initial/final metrics and source gradient/parameter-movement receipts are diagnostics, not held-driven stopping rules.

The primary readout is per-mechanic, program/family-balanced held native and TRAIN-scaled error on supported consequences. Power/HP form one stat mechanic; source cost/location/membership cannot pass this gate. Report every head, including negative results, zero/positive/negative support, distinct roots/templates, rare sign weights, mask counts, per-seed values and null controls. Also report action-pair differences and directions; observed-zero/null contrasts have an absolute-error gate separate from nonzero direction accuracy. Do not allow many unchanged endpoints to dominate the 8/16/16-style mechanic-specific diagnostics.

Report all four cell errors and within-seed marginal C/R differences, plus their interaction. A positive interaction alone does not show either repair is sufficient. Seal any numerical improvement threshold before outcomes; the prior 10% comparison rule and 0.75 contrast-direction criterion are reasonable continuity choices, not newly observed optima. When a comparator error is zero, relative gain is undefined: return null and apply a separately declared native-unit absolute criterion, without adding epsilon. Missing support also yields unsupported/null, not a passing aggregate.

Keep literal zero, TRAIN-mean and one fixed lambda=1 TRAIN-fitted ridge as inexpensive controls. Ridge must disclose its public/program/identity features, weighted objective and intercept treatment; it is not a neural-equivalent optimizer. If affordable, ID-only and a frozen random typed encoder with trained heads should receive the same C1R1 public information and fixed update budget. Held-UNK identity conflicts are an expected control limitation, not proof of semantic transfer. A new shuffle fit is optional: prior sanity already shows arbitrary-label memorization. If used, shuffle complete predeclared compatible target packets, retaining masks/auxiliary labels and documenting tied packets; never choose the permutation by its held score.

The outcome interpretations are fixed:

- C helps only fresh LAW states: evidence for that missing-public-content state generalization, without new aspect-program transfer.
- R helps actual two-endpoint holdouts while conditional results stay unchanged: evidence for the expanded action-binding task, without rewriting the old negative result.
- C1R1 improves over the other cells but loses to zero/mean/ridge or fails signed/contrast support: input sensitivity, not qualified semantic transfer.
- All cells fit TRAIN but fail fresh grouped holdouts: the two repairs are insufficient at this cohort/budget; do not infer that larger capacity is the cause.
- Only consumed bridge scores improve: descriptive compatibility, not fresh validation.
- Corrected native inputs still collide on co-known intended labels, or labels require unobserved/dead/pending states: stop fitting and retain a contract/data finding.
