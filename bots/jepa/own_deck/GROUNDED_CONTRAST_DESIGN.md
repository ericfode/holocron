# Grounded program contrast: independent methodology review

Preparation on `codex/jepa-grounded-contrast`, starting at `bd454609299544a37ec636e32d241d70fd492339`. The earlier negative two-card pilot remains evidence. This reviewer reads source and saved receipts, writes only this document, and launches no collection, model execution, training, or paid work. Kessel remains pinned to `c7ee39554901278cee70f61fd8b26fb1920696b3`; no engine/compiler/card conversion changes are proposed.

The useful question is whether a shared typed program encoder improves **native target admissibility and observable transition prediction on unfamiliar program combinations and states**. More card IDs alone cannot answer it. The prior correct-IR arm did not beat ID-only or fixed wrong IR, both IDs appeared in fitting, three target coordinates were constant, and the fixed wrong mapping was invertible. Those are reasons to change the contrast, not to discard the saved result.

## Native outcomes and useful support

Labels come from actual native offers and settled snapshots, never parser rules, encoder overlap or a synthetic interpreter. For units, a source card click can offer an attack while its activated ability is unavailable; query the exact reviewed ability-menu action separately. Bind source/program/side/stage through native witnesses and preserve intermediate prompts. Each actually offered candidate is committed in an independent branch from the same untouched native target prompt; candidate legality comes from that prompt. An unoffered candidate has a known false admissibility target only when an actual target prompt was observed; otherwise it is unknown. Source availability is measured once per root, not eight independent labels. At most one offered follow-up pass branch is used per root. Only offered tuples may be applied. A skipped second effect, unavailable target, terminal state, or missing follow-up is not an invented observed zero.

Static native review found and corrected two collection assumptions. An actual menu ability can finish without a target when no candidate can change (for example baseline Ready or heal); the offered menu proves source-use, but its absent target prompt supplies no target-membership or target-transition label. Conversely, successful `apply` can pause at a death/program continuation. Final future labels now require terminal status or a finished action Window with ability program, death queues/depth, pending trigger/program queues, after-attack queues, active event group and support pending all clear. Pending snapshots remain evidence with future coordinates masked. Snapshot/legal-action restoration after Cancel and independent prompt copies were preserved. These are read-only source checks, not new execution evidence.

Measure signed target damage/health change, resource payment, target ready/exhaustion change, Shield/Experience changes, survival/public zone changes, terminal status and subsequent affordances where actually observable. Preserve separate masks. If defeat removes a target or resets counters, record the public removal/zone outcome and mask an undefined damage projection; do not reconstruct delivered damage from its IR amount. Settled damage-then-ready behavior must come from native continuation execution. No hidden draw order or opponent private card state enters features or targets.

Before fitting, report for each head and each cell: known count, positive/negative or value counts, distinct contributing program groups, distinct scene families, and actual equal-input/different-program native contrast pairs. Counts of candidate rows do not increase the number of independent roots or programs. Minimum **diagnostic** support is two held-out program groups, at least two held-out scene families, and a nonconstant native target with a measured contrast after accounting for source-form/printed-state differences. A binary head with one class, a continuous head with one value, or one source family cannot validate that head's discrimination. This is a per-head interpretation limit, not a demand to expand runtime coverage. The selected holdouts overlap most cleanly on candidate admissibility: one allows unit targets and the other bases. Their legal committed target domains differ, so damage/readying comparisons are more domain-confounded. Committing all offered candidates improves support but does not remove this limitation. Shield/Experience have no held-out positive effect program here; report their zero-effect tests without claiming positive-effect generalization. Two held-out programs remain too few for population claims or reliable distance rankings.

Use fixed units or scaling fitted **only on the fit cell**, with finite floors and saved inverse scales. Average loss within each available target head, then apply predeclared head weights; global averaging over all known coordinates lets high-availability/trivial heads dominate. Binary weighting uses fit labels only and is capped. Report original-unit per-head errors, balanced accuracy only when both classes occur, and a macro summary of declared nontrivial heads alongside train-prior, zero/copy-current and context-only controls. Constant source exhaustion or always-absent follow-up remains a diagnostic rather than evidence of semantics. Save row-level predictions, native targets, masks and cell/group IDs so the final audit does not need new inference.

## Matched controls and semantic-use diagnostics

The parent authorizes four arms with identical allocated graph/shapes/parameters, initialization, contexts, native labels, batches, optimizer/update budget and final-step selection:

| Arm | Program channel |
| --- | --- |
| Correct IR | Identity-free normalized typed structure and real bound roles |
| ID-only | Opaque fit-identity tokens; all unfamiliar identity groups use one fixed unknown identity token; no AST length/path leakage |
| Wrong IR | Predeclared seeded wrong-program assignment independent of native labels; no persistent source-to-program code shared across fit and held-out groups |
| Unavailable IR / context-only | Uniform program-unavailable mask/status or zero program channel for every row, with no ID fallback or source-slot signal |

A fixed invertible wrong mapping among familiar cards remains only an identity-code control. Prefer a saved per-example/step schedule of non-equivalent wrong programs within the appropriate partition, excluding the true group; never insert held-out labels or held-out programs into the fit input bank. Keep real action roles/context unchanged and wrong IR syntactically known. Freeze this exact rule before fitting. A separate same-weights correct/swap/drop intervention can measure program use; it does not supply labels for altered native cards. Report allocated and effective gradient paths separately: ID/unavailable inputs necessarily activate fewer semantic paths despite an identical graph.

Remove the prior one-copy bag redundancy from this action-semantic pilot: its bag was exactly `query/60`, not independent deck evidence. Active-token mean pooling can reduce the AST-length amplitude cue while retaining ordered path/value interaction, literal quantities and list-length/multiplicity information. None of this modifies the production deck model or establishes dynamic original/remaining-deck semantics.

The saved prior diagnostic used nine forwards and three backwards, zero optimizer steps, with unchanged checkpoint `545ef9b878aacf0b13f95925ed9ab1c5312d2657983489c2223b15460cccce27`. Program-path gradients were nonzero; swapping programs changed logits. The semantic path was not disconnected. Quantity 1→2 altered the damage-head logit RMS by only `4.42e-5`; source exhaustion had much larger influence. These are post-training local, scale-dependent sensitivities, not a reconstruction of training history or native mutant truth. For the next frozen model, retain per-module RMS/nonzero gradient coverage and per-head program-channel gradients/use, plus same-context program swaps, quantity/predicate sensitivity and object-key/instance-renaming invariance. Nonzero gradients alone do not establish correct semantics. Prediction changes must agree with independent native contrast directions where such labels exist.
