# Portable supported-transition evidence

`index.json` maps byte-identical copies to their original local paths and SHA-256
digests. Resolve the copies through this index; absolute paths inside raw
receipts remain historical provenance. The original files are also retained in
the task-7 experiment directory.

This directory contains the actual 16-case dataset, native transition journal,
all attempted-stage receipts, one evidence-bound missing-main quota credit,
600 per-update records, the successful run's event stream, three final
checkpoints, and their fixed numerical contracts and five-status golden arrays.
The checkpoints are standalone research models. They are not production actor
weights or a deployed WASM supplement.

The two-card context holdout cannot establish unseen-card semantics or a useful
behavioral distance. Compare the matched controls and per-target support in
`fit-2/result.json`; several target columns are constant on known observations.
