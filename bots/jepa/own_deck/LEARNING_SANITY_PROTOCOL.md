# Fixed training sanity, one bounded new allocation

This diagnostic checks whether the existing model can fit its observed training
labels before considering another representation. Existing negative held-family
results and their closed campaign remain immutable. It adds authorized exposure;
it does not reset or reuse an earlier cap. The old ledger file hash is
e69410d8… and its final chain record is a4ebccf0…; these are distinct references.

All three arms use the prior saved 11,856-parameter initial checkpoint
(b2f0f1a4…), exactly the existing 16d graph, public twelve-card vocabulary,
TRAIN-only input/literal/head transforms, fixed sign-class weights, head
coefficients and complete auxiliary objective. The typed trainable count is
11,728; unused identity parameters remain allocated and frozen. There is no
new card/native execution or new model representation. Public held-definition
syntax was already allocated; no held labels fit transforms, batches or shuffles.

The arms are correct, fixed-shuffle and fresh-shuffle. Each receives 300 updates
on the same complete 21 TRAIN roots in original order, AdamW .003, decay .0001,
clipping1, same saved initialization and seed17. The minibatch sampling variance
of the earlier fit is removed. Only the jointly known five numeric effect values
at fourteen TRAIN anchors are shuffled. One seeded root-index derangement moves
each five-value packet jointly; power/HP remain coupled. A recipient's public
anchor, inputs, masks, source labels, membership and removal stay fixed. Duplicate
packets can remain numerically unchanged despite a root-index derangement; the
actual changed-vector and per-head fractions are reported. Fixed and all 300
fresh derangements are frozen in the plan and saved before any optimizer update.
Fresh uses the predeclared next mapping each step; no favorable mapping is chosen.

Each arm has one initial and one final all48-root forward. These six calls also
capture vectors and predictions; no export calls are added. Fixed-shuffle reports
TRAIN error against its assigned labels and against true labels separately.
Fresh-shuffle reports true-label initial/final errors and its changing-assignment
training loss, without selecting an evaluation assignment. Auxiliary labels stay
true in every arm, so fresh-shuffle can retain legitimate auxiliary signal.
Correct and fixed-shuffle may both memorize. Neither outcome alone proves leakage
or representation quality.

The correct overfit gate is fixed per each of the five effect heads, on the same
fourteen known TRAIN anchors: final TRAIN-scale MAE <=.05 and final <=.05 times
initial error. If initial error is zero, the ratio is null and only the absolute
error condition applies. Native zero/sign accuracy must be >=.95 per head:
with fourteen roots this requires all fourteen correct. Native predictions in
[-.25,.25] count as zero; values outside it have the corresponding sign. The
head-specific native zero/positive/negative counts and residuals remain visible.
All held errors are reported but never stop training, choose a checkpoint or
extend updates. A failed fixed-budget test remains inconclusive about capacity.

The run has exactly 900 training forwards/backwards/updates and six evaluation
forwards: 906 total, zero extra exports/native/paid work, one CPU, 1GiB sampled
live RSS and 30 active wall seconds including numerical imports. The existing
reviewed own-process Guard is reused. A new single-attempt hash-chained ledger
pins this plan and the old final accounting references. Its exclusive lease
covers import, work and cleanup; every failed started attempt keeps actual time
and the full reserved 900 updates/906 forwards. Pending or finished attempts
block any retry/reset. Pure data/baseline analysis has a separately authorized
10-second allowance and separate source ownership; it must not add neural calls.

The run saves the exact initial checkpoint, all final named weights, initial/final
predictions/vectors, every shuffle schedule, full auxiliary loss traces, preclip
norms and final per-tensor preclip gradient/weight movement. No model, optimizer,
forward or native action is allowed during pure preparation/tests. Root must
freeze/review the source and prepared plan before initializing/executing this
new allocation. No automatic retry, capacity/learning-rate search or joint deck
fine-tuning is authorized.

Before neural work, exact consumed-input hashes are audited on TRAIN for correct
and fixed-assigned labels. Correct contradictions block admission. Fixed-assigned
contradictions remain saved and are interpreted as a logical obstruction to
perfect fitting; the permutation is never replaced. Every one of the five
observed TRAIN sets must equal the same fourteen anchors, so partially observed
labels cannot be silently discarded. Fresh cross-update contradictions are
intentional and counted. Each assignment gathers from immutable original packets
into a new target array; original labels, masks and selected indices are hashed
before/after the run to catch NumPy/Torch storage aliasing. No shuffled mask,
recipient anchor or auxiliary target is permitted.

The quota file is fixed to `experiments/learning-sanity-v1/campaign-ledger.jsonl`.
Initialization stores its canonical absolute path; initialization/execution reject
other paths, including copies of a previously initialized ledger. The prior
campaign is checked byte-for-byte before and after this diagnostic.
